# Checker verification features

| Feature | User outcome |
| --- | --- |
| [Generation progress](generation-progress.md) | Inspect generated, reviewed and retained counts without making model calls. |
| [Frozen sample integrity](sample-integrity.md) | Check exact input bytes, checked contracts and isolated scenario families. |
| [Independent reviews](independent-reviews.md) | Check review identities, recorded model receipts and whole-family exclusions. |
| [Coverage and training readiness](coverage-readiness.md) | See which observed tools and decision conditions remain uncovered. |
| [Export and CPU audit](export-cpu-audit.md) | Verify a fresh export boundary and audit a frozen snapshot without executing samples. |
